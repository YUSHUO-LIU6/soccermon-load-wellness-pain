# Source-data attribution and reuse

Source: Cise Midoglu, Matthias Boeker, Andreas Kjæreng Winther, Svein Arne
Pettersen, Dag Johansen, Michael Riegler, Pål Halvorsen and Steven Hicks.
*SoccerMon: A Large-Scale Multivariate Soccer Athlete Health, Performance,
and Position Monitoring Dataset*. Zenodo.
[Dataset DOI](https://doi.org/10.5281/zenodo.10033832).

The [DataCite DOI metadata](https://api.datacite.org/dois/10.5281/zenodo.10033832),
retrieved 2026-11-23, records **Creative Commons Attribution 4.0 International**
([license terms](https://creativecommons.org/licenses/by/4.0/legalcode)).
The Zenodo page's machine-readable browser view did not display a license
identifier; the DOI registry supplies the explicit rights metadata. Its
retrieved response hash is recorded in the execution manifest.

This project derives episode counts, player-day risk sets, lagged exposures,
standardized variables and regression summaries from the subjective release.
These are transformations by the secondary-analysis authors. Raw monitoring
files and fresh player-day outputs are not bundled in Git. Frozen player-linked event/influence summaries and the associated discrepancy
ledgers retain the source's anonymized identifiers. They can be linked across the public source and should not be
represented as unidentifiable aggregate coefficients. No reidentification was
attempted. Preserve source credit and the change description when reusing
these derived materials; the original creators do not endorse this analysis.

The article's license, the dataset's recorded license, ownership of project
code and the software license are separate matters. The code rights holders explicitly authorized the [MIT software license](../LICENSE)
on 2026-11-23. This authorization covers project-owned code; it does not
relicense third-party data or the published source materials. No third-party software installation,
external thesis, instrument screenshot or source article is bundled in the
proposed repository changes.
